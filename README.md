# Minha Liturgia

Aplicativo católico de liturgia diária, Bíblia, terço e orações.

- `minha-liturgia/` — PWA (site hospedado via GitHub Pages em [wagneralvesjdi.github.io/minha-liturgia/](https://wagneralvesjdi.github.io/minha-liturgia/)).
- `minha-liturgia-playstore/` — versão Android (TWA) para a Google Play Store. Veja o README dentro dessa pasta para instruções de build e publicação.
